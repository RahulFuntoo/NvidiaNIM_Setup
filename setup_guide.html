Claude Code Free Setup

A professional technical guide to configuring the Claude Code CLI using NVIDIA NIM and open-source proxy routing.

1 Install Claude Code

The first requirement is the official Claude Code CLI developed by Anthropic.

1. Visit the official Claude Code website to get the most recent install command.
2. Open your Terminal (zsh/bash on Mac/Linux, or WSL/Ubuntu on Windows).
3. Execute the installation script:
curl -fsSL https://claude.ai/install.sh | bash
Important: Do not run the claude command just yet. We must configure the proxy routing first to avoid official billing.

2 Install uv and Python

To run the proxy server, we use uv, an extremely fast Python package and project manager.

1. Install the uv binary using the official astral.sh script:
curl -LsSf https://astral.sh/uv/install.sh | sh
2. Install Python 3.14 via uv:
uv python install 3.14

3 Clone Proxy Server Repository

Instead of running heavy local models (Ollama/LM Studio), we use a proxy that routes requests to high-performance cloud APIs.

1. Create a dedicated directory for the proxy and clone the repository:
git clone https://github.com/Alishahryar1/free-claude-code.git nvidia-nim cd nvidia-nim
2. Initialize the environment configuration file:
cp .env.example .env
3. Open this folder in your preferred editor (e.g., code . for VS Code) to begin configuration.

4 Obtain Free API Keys

You will need API keys to authorize the proxy server. NVIDIA NIM is highly recommended for stability and speed.

Action: Open the .env file and populate the following fields:
1.
NVIDIA NIM (Recommended):
Create an account at build.nvidia.com, verify via phone, and generate a key named "CC". Paste this into NVIDIA_API_KEY.
2.
OpenRouter (Optional):
Generate a key at openrouter.ai and paste it into OPENROUTER_API_KEY.
3.
DeepSeek (Optional):
Generate a key at platform.deepseek.com and paste it into DEEPSEEK_API_KEY.

Save your .env file before proceeding.

5 Configure the Models

Claude Code expects specific model tiers (Opus, Sonnet, Haiku). We map these to our free endpoints in the configuration file.

1.
Opus Mapping: Use NVIDIA GLM. Go to NVIDIA NIM, filter by "Free Endpoint", copy the model string, and format as:
nvidia/[model-name] (e.g., nvidia/glm-4.7)
2.
Sonnet Mapping: Use OpenRouter's top free models. Format as:
openrouter/[model-name] (e.g., openrouter/google/gemma-2-27b)
3.
Haiku Mapping: Use DeepSeek Reasoner. Format as:
deepseek/deepseek-reasoner

6 Run and Launch

Finally, start the proxy server and launch the Claude CLI with redirected environment variables.

1.
Start the Proxy Server: (In the nvidia-nim folder)
uv run uvicorn server:app --host 0.0.0.0 --port 8082
Note: Keep this terminal window open. The proxy server must be active for Claude Code to function.
2.
Launch Claude Code: Open a NEW terminal, navigate to your actual project folder, and run:
ANTHROPIC_AUTH_TOKEN="freecc" ANTHROPIC_BASE_URL="http://localhost:8082" claude

Conclusion

You have successfully bypassed the high cost of AI coding agents by utilizing NVIDIA NIM and a lightweight proxy. You now have a professional-grade coding assistant capable of complex file edits and architectural decisions without the monthly subscription fee.

Pro Tip: Once inside Claude Code, type /sandbox and select "Sandbox with auto-allow" to eliminate tedious per-file permissions.
