Free Claude Code Setup

Using OpenCode AI API for free access to Claude Code with powerful AI capabilities.

Prerequisites

Required Software

  • Node.js installed
  • VS Code or other IDE installed
  • Claude Code installed

1 Install OpenCode

1. Open your terminal (PowerShell or CMD) and run the following installation command:
npm i -g opencode-ai

2 Connect to OpenCode

1. Call /connect in your terminal
2. Select opencodezen from the options

3 Get API Key

Create your API key from OpenCode to authenticate your connection.

Steps:
1. Open and login at opencode.ai/zen
2. Go to API keys: opencode.ai workspace keys
3. Create a new API key and copy it
4. Enter your API key when prompted

4 Configure Claude Settings

1. Open the Claude configuration folder:
C:\Users\YOUR_USER\.claude
2. Edit settings.json and add the following environment variables:
"env": { "ANTHROPIC_BASE_URL": "https://opencode.ai/zen", "ANTHROPIC_MODEL": "minimax-m2.5-free", "ANTHROPIC_API_KEY": "YOUR_API_KEY", "ENABLE_TOOL_SEARCH": "true" }

5 Activate Free Claude Code

1. Open VS Code and launch the terminal
2. Type claude to start
Note: When prompted, select "yes" to use the API key. Press enter twice to confirm and activate free Claude Code.
